CrowdStance — Future Plans

Short Term

Fine-tune stance detection model on Reddit-specific data to improve accuracy on sarcastic and context-dependent comments
Improve comment filtering to remove low-quality and bot-generated content
Deploy the application publicly via Railway or Render for live access without local setup

Medium Term

Expand platform coverage to include Twitter/X and YouTube comments
Add user accounts with saved searches and search history
Implement longitudinal tracking to monitor how opinions shift over time on a topic
Integrate a larger LLM (GPT-4o or Claude) for richer argument summarization and explanation generation
Add follow-up question support so users can ask clarifying questions about the results

Long Term

Build a public API so developers can query CrowdStance programmatically
Add multilingual support for non-English communities
Train a custom stance detection model specifically for online discourse
Use LLM-generated rebuttals to surface the strongest counterarguments for any stance
Add a fact-checking layer that cross-references claims in comments against trusted sources
